Entropy & brute-force lab

Why “just generate millions of keys and try them” cannot work — the arithmetic, per provider.

The math in four lines

  • A key’s search space is charsetlength. OpenAI ≈ 6248 ≈ 2285 — more candidates than atoms in the observable universe, squared.
  • Blind guessing needs ~half the keyspace on average for one hit. Even at 1012 probes/second, that’s ~1066 years — the universe is 1.4 × 1010 years old.
  • Real auth endpoints rate-limit and lock out after a handful of failures, so the effective rate is worse than any number below — and probing third-party auth with guessed credentials is illegal (CFAA/CMA and equivalents) and against every provider’s ToS.
  • Keys you hear about being “found” were leaked (repos, logs, screenshots) — not guessed. Protect against leaks: short lifetimes, scopes, rotation, secret scanning.

“Key bits” is pure format entropy (log2 of the keyspace) — the floor for how unpredictable a well-generated real key is. Expected time assumes one perfect oracle and zero rate limiting; reality is slower by orders of magnitude.

Install & about

Keyshape is a Progressive Web App: installable, offline-capable, no account, no telemetry.

Install as an app

  1. Android / desktop Chrome & Edge: use the install button above, or the install icon in the address bar.
  2. iPhone / iPad (Safari): Share → Add to Home Screen.
  3. Offline: after the first visit everything works with no network — the service worker caches the whole app.

What about an Android APK?

The installed PWA is the app: standalone window, home-screen icon, offline. If you specifically need a store-style .apk, wrap this same build in a Trusted Web Activity or Capacitor shell — the README documents the one-keystore flow. There is deliberately no background service: an app that quietly probes third-party auth endpoints is malware, and this project has nothing to probe — it never contacts provider APIs.

What this is — and what it is not

  • Is: a format catalog for 57 providers, a synthetic fixture generator, a local format validator, and an entropy calculator — for developers testing key handling, mock flows and secret-scanning rules.
  • Isn’t: a key “finder”. Guessing credentials against real services to land a working key is account theft — illegal under computer-misuse law and against every listed provider’s terms — and the entropy tab shows it’s mathematically hopeless regardless.
  • Privacy: 100% client-side. No analytics, no storage of your inputs, no network calls except static assets.

Custom provider

Need a format that isn’t listed? The generator supports fully custom shapes (prefix · suffix · length · alphabet) — pick Custom provider at the top of the Generate tab.

Core logic is dependency-free ES modules with npm test unit coverage. MIT licensed.
